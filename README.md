# AetherCommerce

1. Install Node.js 18.17+ (https://nodejs.org)
2. Open this folder in VS Code, then in the terminal:
   npm install
   npm run dev
3. Open http://localhost:3000

Deploy: push to GitHub and import on Vercel (no env vars needed).

Structure:
  src/app/layout.tsx, page.tsx, globals.css
  src/components/Hero.tsx, StorefrontSandbox.tsx, CaseStudyDrawer.tsx
  src/data/mockData.ts
